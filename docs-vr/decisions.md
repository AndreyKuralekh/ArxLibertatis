# Arx VR — принятые решения

Кратко: дата, решение, причина. Новые решения — внизу.

## 2026-09-24 — этап 0

1. **Ветка `vr` от `upstream/master` (1.3-dev, коммит `5b95e4c`), а не от тега `1.2.1`.**
   `master` впереди 1.2.1 на ~2750 коммитов (в т.ч. улучшения физики и рендера), последний коммит 2024-08-22.
   Регулярно подтягивать upstream проще всего от `master`; от 1.2.1 слияния были бы тяжёлыми.

2. **Форк `AndreyKuralekh/ArxLibertatis` (публичный) как `origin`, `arx/ArxLibertatis` как `upstream`.**
   Код GPL — публичный форк допустим. Данных игры в репозитории нет и не будет.

3. **Сборка: генератор Visual Studio 17 2022, x64, конфигурация RelWithDebInfo.**
   Ninja не подходит: движок добавляет флаги компилятора C++ без генераторных выражений, и с Ninja они
   попадают в `rc.exe` (`RC1203: invalid language ID`). Генератор VS фильтрует их сам.

4. **Зависимости — готовые библиотеки `arx/ArxWindows\libs` через `CMAKE_PREFIX_PATH`**, суперсборку
   ArxWindows (сабмодуль `arx`) не используем. Для Boost — шим `cmake-shims\Boost\BoostConfig.cmake` вне
   репозитория: движок включает политику CMP0167 NEW (нет встроенного FindBoost в CMake 3.30+),
   а в ArxWindows только заголовки Boost 1.76. Код движка не меняли.

5. **Данные игры вне репозитория**: копия Steam-версии (патч 1.21) в `..\gamedata\`, пользовательские файлы
   (конфиг, лог, сохранения) — в `..\userdata\` через `-u`/`-c`. Запуск с `-n`, чтобы данные брались только из
   явно указанных папок. `.gitignore` форка дополнительно исключает `/gamedata/`, `/logs/`, `*.pak`.

6. **Русский язык задаётся в конфиге** (`[language] string="russian"`, `audio="russian"`): автоопределение
   идёт по локали системы (en-US) и выбирает английский.

7. **Документация — в репозитории, `docs-vr/`**, чтобы версионироваться вместе с кодом ветки `vr`.
   Имя `docs-vr`, чтобы не пересекаться с upstream-папками при слиянии.

## 2026-09-24 — этап 1

8. **Стерео через перепроекцию, а не двойной рендер кадра.** Движок проецирует почти всю не-фоновую геометрию
   на CPU в пиксели одной камеры (`TexturedVertex` = неразделённые однородные координаты). В VR это «моно-камера»
   в центре головы с FOV, покрывающим оба глаза; для каждого глаза `disableTransform()` загружает
   `P_eye · (глаз←камера) · (пиксели→вид камеры)⁻¹` (`OpenGLRenderer::setTexturedVertexTransform`). Комнаты,
   вода, лава используют матрицы глаза напрямую. Обновление эффектов выполняется один раз за кадр, на глаз
   повторяется только отрисовка. Причина: двойной `renderLevel` потребовал бы разделить update/draw у ~10 функций
   и ~24 заклинаний.
9. **Перепроекция считается в double и без мировых координат.** Обращение полной матрицы мир→пиксели во float
   давало дрожание моделей (координаты мира — тысячи единиц). Смещение глаза берётся из трекинга.
10. **Вся 2D-графика — в UI-FBO фиксированного размера 1280×720** (`xr::getUiSize()`), показывается quad-слоем
    OpenXR перед точкой recenter: непрозрачно в меню/заставках, прозрачным оверлеем (premultiplied alpha) в игре.
    `g_size` в VR = размер панели, не окна; мышь пересчитывается из пикселей окна. Окно — только зеркало 960×540.
11. **Тело и голова.** Yaw тела хранится отдельно; игрок смотрит и идёт по взгляду (yaw игрока = тело + голова),
    повороты мышью/клавишами/скриптами/snap-поворот добавляются к телу. Pitch игрока = 0 (иначе смещается
    точка камеры на модели), без покачивания и тряски камеры. Recenter — при надевании шлема и нажатием правого стика.
12. **Кадр OpenXR:** `xrWaitFrame/BeginFrame/LocateViews` — сразу после `xrEndFrame` предыдущего кадра
    (в `showFrame()`), поэтому экраны загрузки и логотипы тоже попадают в шлем.
13. **Раскладка контроллеров (этап 1):** правый луч + курок = мышь/ЛКМ (действие, удар, руны),
    правый grip = ПКМ, левый стик = ходьба/стрейф, правый стик ←/→ = snap 45°, ↑/↓ = колесо, A = прыжок,
    B = присед (toggle), X = инвентарь, Y = книга, левый grip = режим магии, левый курок = оружие,
    меню = Esc, нажатие правого стика = recenter. Взаимодействие с миром — прицелом по взгляду.
14. **Рантайм для тестов — Virtual Desktop (VDXR)** с реальным шлемом; Meta XR Simulator не понадобился.

## 2026-09-25 — этап 1, доводка по итогам прохождения

15. **Правый grip = действие USE** (взять/использовать/открыть — в Arx это `F`), а не правая кнопка мыши:
    ПКМ в Arx — FREELOOK (переключение взгляд/курсор), grip из-за этого «центрировал» вид.
16. **Нажатие левого стика = FREELOOK** (переключение прицел по взгляду ↔ курсор): в режиме прицела игра не
    читает курсор, а значки HUD (лестница, книга, рюкзак) кликаются только курсором.
17. **Прицел рисуется в 3D** — квад на 1,5 м по оси взгляда в каждом глазу (та же перепроекция), а не на
    HUD-панели, которая не движется с головой.
18. **HUD-панель лениво следует за головой**: доворачивается, если взгляд ушёл от неё больше чем на 40°.
    Луч контроллера рисуется поверх глаз, когда указывает на панель.
19. **Исправлен баг upstream 1.3-dev**: `EntityManager::clear()` падал на висячем владельце предмета
    (понятие owner, коммит upstream `502aeee`) — «Новая игра»/загрузка из уровня. Кандидат на отправку в upstream.
